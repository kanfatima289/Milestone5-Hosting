# Review Intelligence Workflow Showcase

A static, single-page showcase for the n8n Review Intelligence + Fee Explainer workflow.

## Publish with GitHub Pages

1. Create a GitHub repository. Use **Public** visibility if anyone with the URL should be able to view the site.
2. Upload `index.html` and `.nojekyll` to the repository's top level (or upload the contents of this folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then select **Save**.
6. Wait for the Pages deployment to complete. GitHub shows the live URL in **Settings → Pages**.

The site is static and requires no build step. The CSV preview runs in the browser and does not upload the selected file. Sample run cards are illustrative saved output; approval buttons are simulations and do not call n8n, Google Docs, or Gmail.
